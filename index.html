شیکردنەوەی ڕاستەقینەی زیندوو

کامێرای زیرەک — شیکردنەوەی زیندووی کامێرا

کامێرا چالاک بکە، بگەڕێ یان زووم بکە — سیستەمەکە بە شیکردنەوەی ڕاستەقینەی وێنە (بە Claude AI) کەسەکان دەدۆزێتەوە و وەسفیان دەکات: دووری، جۆری جلوبەرگ و بەرزی باڵای خەمڵێنراو.

کامێرا هێشتا چالاک نییە
زووم 1.0x
وێنە بۆ Claude API دەنێردرێت تەنها بۆ شیکردنەوە و هەڵناگیرێت. خەمڵاندنی دووری و بەرزی باڵا نزیکەین، نەک وردەکاری ڕاستەقینەی وردبین.
تێبینی: ئەگەر لەناو پێشبینینی ئەم چاتەدا دەستگەیشتنی کامێرا کارنەکرد، فایلەکە بار بکە بۆ GitHub Pages (یان هەر هۆستکردنێکی HTTPS) و لەوێ تاقی بکەرەوە.
