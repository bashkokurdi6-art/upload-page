ڕێکخستنی Puter

هیچ کلیل و هیچ ڕێکخستنێکی زیاتر ناوێت. یەکەم جارێک کە پەیامێک بنێریت، پەنجەرەیەکی بچووکی Puter دەکرێتەوە داوات لێدەکات هەژمارێکی بەخۆڕایی دروست بکەیت یان بچیتە ژوورەوە (چرکەیەک تێدەچێت). دوای ئەوە هەموو شتێک بەخۆڕاییە.

کلیلی API

کلیلەکەت لە Anthropic Console وەربگرە. تێبینی: ئەم پەڕەیە ڕاستەوخۆ لە وێبگەڕەکەتەوە پەیوەندی بە API ـەوە دەکات، بۆیە کلیلەکەت لەناو ئامێرەکەی خۆتدا دەمێنێتەوە و بۆ هیچ سێرڤەرێکی تر نانێردرێت.

ڕێکخستنی Ollama

بۆ بەکارهێنانی ئەم ڕێگایە بەخۆڕاییە:
١. Ollama دابەزێنە لە ollama.com
٢. لە تێرمیناڵدا بنووسە: ollama pull llama3.2
٣. دڵنیابەرەوە کە Ollama کاردەکات (بە شێوەی ئۆتۆماتیکی دوای دامەزراندن کاردەکات)
٤. ئەگەر هەڵەی پەیوەندی (CORS) بینیت، Ollama بە فەرمانی OLLAMA_ORIGINS=* ollama serve دەستپێبکەرەوە
